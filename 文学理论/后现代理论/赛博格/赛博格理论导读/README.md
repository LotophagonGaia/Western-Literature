# 《赛博格理论导读：从控制论到后人类》

## 作品简介

本书是一部关于赛博格（Cyborg）理论的系统性导读，试图梳理“赛博格”这一概念从20世纪60年代的航天医学与控制论出发，经由科幻文学、唐娜·哈拉维的《赛博格宣言》、后人类主义与延展心灵理论，直至当代平台社会与人工智能研究的发展脉络。

全书以“控制与解放”的张力为主线，分为五个部分、十九章，并附有术语表、人物速查、参考书目与讨论问题，旨在为希望系统了解赛博格理论及其思想背景的读者提供一条相对完整的阅读路径。
